# 実装済み機能（ラブ万歩計）

2026-07-26時点でコードベースから確認できた実装済み機能の一覧。
未実装・未完成の項目は `未解決の問題.md` を参照。

## コア機能

- [x] 歩数計測（StepCounter/StepDetectorセンサー、日次・時間別記録）
- [x] フォアグラウンドサービスによるバックグラウンド計測
- [x] 端末再起動時の自動再開（BootReceiver）
- [x] WorkManagerによるサービス生存監視・再起動
- [x] 歩数→行動ポイント換算（2,000歩=1pt、1日上限5pt）

## 好感度・キャラクターシステム

- [x] ラブレベル（1〜10）＋ハートゲージ（0〜10）による好感度管理
- [x] 累積総歩数の壁によるレベルアップ制御（ハート満タン＋歩数条件の両方が必要）
- [x] レベルダウン（ハート0で追加減少時にラブレベル-1）
- [x] レベルアップ演出ダイアログ
- [x] キャラクタータッチ演出・セリフ分岐（待機中／タッチ／連続タッチ／寂しさ／
      天気連動／好感度帯別）
- [x] 好感度帯別の呼称（知り合い／仲良し／好き／恋愛中／深愛）

## AIチャット

- [x] ホーム画面AIチャット（Gemini経由、ラブレベル変動あり）
- [x] 恋人モード（旧おしゃべり、ラブレベル9で解禁、写真添付対応、
      ラブレベル非連動）
- [x] 会話への歩数・活動日数・前日日記内容の反映
- [x] 感情タグ（`[EMOTION:xxx]`）によるハート増減・表情反映

## 日記

- [x] ユーザー手書き日記（テキスト・気分・写真）
- [x] 翌日のAI自動返信
- [x] AIによる内部記憶用の日次要約生成（ユーザー日記とは別データ）

## ショップ・着替え・コレクション

- [x] ショップ（衣装購入、行動ポイント通貨、7種の衣装）
- [x] 着替え（所持衣装の装備切り替え）
- [x] おもいで（Memories、好感度到達で解放されるコレクション、9種）

## 記録・情報表示

- [x] 記録画面（日/週/月/年別グラフ、速度・カロリー・活動時間集計）
- [x] 天気表示（現在＋時間別、地名つき、Open-Meteo API）
- [x] BGM選択・音量調整（3曲＋オフ）
- [x] フォアグラウンド通知（今日の歩数＋好感度帯別セリフ）
